## Temas dominados

**Conceptual:**
- ✅ filter → retorna TODOS los elementos que cumplen la condición
- ✅ find → retorna solo el PRIMER elemento que cumple la condición
- ✅ find retorna undefined si no encuentra nada
- ✅ includes recibe un valor directo, no una función
- ✅ filter y find NO modifican el array original

**Práctico:**
- ✅ && para combinar dos condiciones en filter
- ✅ endsWith vs includes — cuándo usar cada uno para mayor precisión
- ✅ findIndex retorna la posición del elemento encontrado
- ✅ includes retorna true/false directamente — no necesita === true

**Correcciones importantes:**

- ✅ Corrigió == por === en findIndex
